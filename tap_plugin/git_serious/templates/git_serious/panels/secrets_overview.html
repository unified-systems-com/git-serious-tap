Provenance — where these facts come from

Secrets are github_core__actions_secret nodes landed by the github_core collector from GitHub's organisation, repository and environment secret listings — name, timestamps and (organisation only) visibility; GitHub's API has no value field, so none is stored. DEFINES_SECRET joins each to its holder; REFERENCES_SECRET joins each workflow whose file names it inside an expression, one edge per defining scope. A name no listed scope defines is recorded on the workflow (tags.secret_refs.unresolved) beside the scopes that were read, never as a node — minting a secret from a reference would assert a credential exists because somebody typed its name. Runs, triggers, repository visibility and criticality are github_core's; findings are zizmor's when it is installed{% if not estate.scanner_present %} (it is not on this grid — that column is not observable){% endif %}.
